# Giant Traders Academy — Independence Day 2026

## GitHub Pages
Upload this folder to your repository.

The campaign page is:
`/independence-day/`

If your GitHub Pages site is `https://YOUR-USERNAME.github.io/YOUR-REPO/`, the campaign URL becomes:
`https://YOUR-USERNAME.github.io/YOUR-REPO/independence-day/`

The campaign countdown is fixed to **18 August 2026, 11:59 PM IST**.

The campaign page links back to the existing GTA homepage at `../index.html`.

No external JavaScript libraries are required.
